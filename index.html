২. ফোল্ডার স্ট্রাকচার

Vercel এ deploy করতে হলে নিচের ফোল্ডার স্ট্রাকচার অনুসরণ করুন:

my-backend/
├── api/
│   └── index.ts          ← Vercel এর entry point
├── prisma/
│   ├── schema.prisma     ← Database schema
│   └── migrations/       ← Migration files
├── src/
│   ├── config/
│   │   ├── env.ts
│   │   └── prisma.ts     ← Prisma client
│   ├── generated/
│   │   └── prisma/       ← Generated client (git এ রাখুন!)
│   ├── middlewares/
│   ├── modules/
│   └── utils/
├── .env                  ← Local env (gitignore)
├── .gitignore
├── package.json
├── prisma.config.ts      ← Prisma v7 config
├── tsconfig.json
└── vercel.json           ← Vercel config
⚠️ সতর্কতা: src/generated/ ফোল্ডারটি .gitignore এ যোগ করবেন না! GitHub এ push করতে হবে।

৩. package.json কনফিগারেশন

⚠️ সতর্কতা: "type": "module" কখনো যোগ করবেন না! Vercel serverless এ CommonJS এর সাথে conflict করে।

সঠিক package.json:

{
  "name": "my-backend",
  "version": "1.0.0",
  // ❌ "type": "module"  — এটা দেবেন না!
  "scripts": {
    "dev": "ts-node-dev --respawn --transpile-only src/server.ts",
    "build": "prisma generate && tsc",
    "start": "node dist/server.js",
    "postinstall": "prisma generate"  // ✅ Vercel এ auto-run
  },
  "dependencies": {
    "@prisma/client": "^7.x",
    "@prisma/adapter-pg": "^7.x",
    "express": "^5.x",
    "pg": "^8.x",
    ...
  },
  "devDependencies": {
    "prisma": "^7.x",
    "typescript": "^5.x",
    "ts-node-dev": "^2.x",
    ...
  }
}

গুরুত্বপূর্ণ scripts:

  • "postinstall": "prisma generate" — Vercel deploy এর সময় auto-run হয়
  • "build": "prisma generate && tsc" — build এ prisma generate আগে চলে

৪. tsconfig.json কনফিগারেশন

⚠️ সতর্কতা: module: "commonjs" এবং moduleResolution: "node" ব্যবহার করুন। "nodenext" Vercel এ সমস্যা করে।
{
  "compilerOptions": {
    "rootDir": "./",
    "outDir": "./dist",
    "module": "commonjs",        // ✅ commonjs — nodenext নয়
    "moduleResolution": "node",  // ✅ node — node16/nodenext নয়
    "target": "esnext",
    "lib": ["esnext", "dom"],
    "types": ["node"],
    "strict": true,
    "skipLibCheck": true,
    "esModuleInterop": true,
    "isolatedModules": true,
    "moduleDetection": "force",
    "sourceMap": true,
    "declaration": true,
    "declarationMap": true
  },
  "exclude": ["node_modules", "dist"],
  "include": [
    "src/**/*",
    "api/**/*",            // ✅ api/ ফোল্ডার include
    "src/generated/**/*",  // ✅ generated client include
    "prisma/**/*.ts"       // ✅ prisma.config.ts include
  ]
}

সাধারণ ভুল:

  • ❌ module: "nodenext" — .js extension বাধ্যতামূলক হয়, Vercel এ সমস্যা
  • ❌ "type": "module" in package.json — CommonJS conflict
  • ✅ module: "commonjs" + moduleResolution: "node" — সবচেয়ে stable

৫. prisma.config.ts কনফিগারেশন

Prisma v7 এ datasource এ url দেওয়া যায় না। prisma.config.ts এ দিতে হয়:

/// <reference types="node" />  // ← এটা উপরে দিতে হবে
import "dotenv/config";
import { defineConfig } from "prisma/config";

export default defineConfig({
  schema: "prisma/schema.prisma",
  migrations: {
    path: "prisma/migrations",
  },
  datasource: {
    url: process.env["DATABASE_URL"],
  },
});
💡 নোট: /// <reference types="node" /> না দিলে process এ TypeScript error আসে।

schema.prisma — url বাদ দিন:

generator client {
  provider = "prisma-client-js"
  output   = "../src/generated/prisma"
}

datasource db {
  provider = "postgresql"
  // ❌ url = env("DATABASE_URL") — Prisma v7 এ এটা দেবেন না
}

৬. src/config/prisma.ts

Prisma v7 এ PrismaClient এ adapter দিতে হয়। adapter ছাড়া PrismaClient() কাজ করে না:

import { PrismaClient } from "../generated/prisma/client.js";
import { PrismaPg } from "@prisma/adapter-pg";
import pg from "pg";

const globalForPrisma = globalThis as unknown as {
  prisma: PrismaClient | undefined;
};

// DATABASE_URL দিয়ে connection pool তৈরি
const pool = new pg.Pool({
  connectionString: process.env.DATABASE_URL,
});

const adapter = new PrismaPg(pool as any);

export const prisma =
  globalForPrisma.prisma ??
  new PrismaClient({
    adapter,  // adapter দেওয়া বাধ্যতামূলক
  });

if (process.env.NODE_ENV !== "production") {
  globalForPrisma.prisma = prisma;
}
💡 নোট: globalForPrisma pattern hot-reload এ duplicate connection prevent করে।

৭. vercel.json কনফিগারেশন

Backend root এ vercel.json বানান:

{
  "version": 2,
  "buildCommand": "prisma generate && tsc",
  "builds": [
    {
      "src": "api/index.ts",
      "use": "@vercel/node"
    }
  ],
  "routes": [
    {
      "src": "/(.*)",
      "dest": "api/index.ts"
    }
  ]
}

api/index.ts — Vercel entry point:

import app from "../src/app";
export default app;
✅ গুরুত্বপূর্ণ: "buildCommand" এ prisma generate দিলে Vercel build এর সময় client generate হয়।

৮. Environment Variables

Local .env ফাইল:

DATABASE_URL="postgresql://user:pass@ep-xxx-pooler.neon.tech/neondb?sslmode=require"
DIRECT_URL="postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require"
JWT_SECRET="your_super_secret_key_here"
JWT_EXPIRES_IN="15m"
NODE_ENV="development"
PORT=5000

DATABASE_URL vs DIRECT_URL পার্থক্য:

VariableURL Typeকাজ
DATABASE_URL...pooler.neon.tech... (pooler)Runtime — PrismaClient এ ব্যবহার হয়
DIRECT_URL...neon.tech... (-pooler ছাড়া)Migration এর জন্য — prisma.config.ts এ
💡 নোট: DIRECT_URL তৈরি করতে DATABASE_URL থেকে শুধু -pooler অংশটা সরিয়ে দিন।

১৩. দ্রুত কমান্ড রেফারেন্স

প্রতিদিনের কাজে:

# Development server start
npm run dev

# Prisma client generate
npx prisma generate

# New migration তৈরি
npx prisma migrate dev --name migration_name

# Production migration deploy
npx prisma migrate deploy

# Database schema push (migration ছাড়া)
npx prisma db push

# Prisma Studio (Database GUI)
npx prisma studio

GitHub Push:

git add .
git commit -m "your commit message"
git push -u origin main

Build Test Local এ:

# Build করুন
npm run build

# Build output চেক করুন
ls dist/

# Production mode এ run করুন
npm start
